Connected Paediatrics Cranial Shape Analyser PWA v1.8

Upload all SIX web files to the ROOT of your Plagiocephaly GitHub repository:
index.html
manifest.json
service-worker.js
icon-192.png
icon-512.png
apple-touch-icon.png

README.txt is guidance only; you do not need to upload it.
Enable GitHub Pages: Settings > Pages > Deploy from branch > main > / (root).
On iPhone/iPad: open the published site in Safari, Share > Add to Home Screen.
Photos are processed locally and are not cached by the service worker. Findings are saved in browser-local storage; installed app storage may be separate from Safari.

New: Connected Paediatrics community link (requires internet).
